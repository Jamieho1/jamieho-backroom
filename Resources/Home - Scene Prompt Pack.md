## Shared visual instruction

Photographic, recognisable London with crisp fine architectural detail and only a very slight polished illustrated finish consistent with the approved original sky artwork. Preserve real proportions, material response and stable lighting within each shot. Motion is grounded, coherent and cinematic, with controlled eye-level travel and stronger parallax in nearby structure than distant buildings. No toy diorama, waxy plastic city, warped architecture, sudden viewpoint jump, digital zoom substituted for forward travel, invented landmark rearrangement, text overlays, UI, watermark, generated personal copy or audio. Keep every paused intermediate frame composed and sharp. Use the supplied references for their stated role; do not silently change viewpoint, weather or identity.

## Input roles and production settings

For each scene identify a start image, any optional end image, architecture/context references and treatment reference. A start image governs framing; an architecture reference from another angle does not. A style image does not authorize copying its subjects into another scene. Use supported reference roles from the actual model schema.

Place duration, aspect ratio, resolution, draft mode and audio switches in the tool's settings as well as describing intent in the prompt. Use one output for a test. Prefer native source detail and stable motion over an upscale label. For a different free provider, inspect its actual model/duration/reference support rather than copying unsupported API parameters.
