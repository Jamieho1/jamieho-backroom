## Before selecting pilot assets

For each selected shot, record source URL/creator, camera direction/height and intended movement, foreground/midground/background, colour/light cues, needed occluder, production-use provenance and any interpretation. Review the exact frames/crops rather than approving an entire search result or gallery as if it were a final asset.

First pilot still proves within-scene progression, one covered pause/reverse connection and the room/monitor behavior before full production. This shortlist does not authorize generation, downloads into Git, runtime changes or paid/account actions.
