# Local and API audit — 1 November 2026

Jamie authorized an audit and fixes for layout/mobile overflow, save/retry behavior and access control.
No live website or personal browser was used. No production content or credentials were read.

## Fixed findings

| Finding | Result |
| --- | --- |
| Practice's first saved-data load could fail, leaving Save available before the remote code was known. Retry loaded metadata but offered no way to open the recovered server code. | Save stays disabled until a successful read. Retry preserves current typing; Load saved code explicitly opens the recovered version. Restore browser draft retains the latest locally typed draft, including when switching between the two copies. |
| An older owner profile request could finish after sign-out or an account switch, restoring stale owner UI. | Request generations discard stale responses; sign-out and identity changes clear editing. Protected views refresh to recheck their server-rendered access. Database/server write guards already applied independently. |
| Public-page icon discovery was keyed by role and display name, which can match across two different accounts. | Discovery also depends on authenticated user ID; same-name account switches reload the permitted icons. |

These changes do not alter Notes/Practice layout or add data collection. They do not merge conflicting
edits from two devices; explicit Save remains the current cross-device synchronization model.
